# Background Audio Directory

Place your audio file here as:
`bgm.mp3`

Supported formats: `.mp3`, `.m4a`, `.wav`, `.ogg`.

If you don't add a file yet, the website features a built-in gentle acoustic / music-box ambient melody so the experience sounds wonderful out-of-the-box!
You can also change the audio path or URL in `src/data/scrapbookData.js`.
